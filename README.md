# Hi, I'm Jing Li

I'm a full-stack software engineer with an M.S. in Computer Science from Georgia Tech.

## Featured projects

### ByteDuel
A real-time platform where players write bots in C++, Java, Python, or Go
and watch them compete in live matches. I built WebSocket match updates
and a compilation cache that reduced median repeat Go bot checks
from 287 ms to 8.5 ms in benchmarks.

**Stack:** Java, Spring Boot, Vue 3, PostgreSQL, Docker

[Source code](https://github.com/Wildlife7609/ByteDuel) · [Live demo](https://byteduel.de5.net/)

### AIFriends
A text and voice chat app with customizable AI characters and long-term memory.
I built streaming audio replies that reduced the median time to first audio
from about 6 seconds to 1.5 seconds across five local tests.

**Stack:** Python, Django, Vue 3, LangGraph, Gemini

[Source code](https://github.com/Wildlife7609/AIFriends) · [Live demo](https://aifriends.de5.net/)
